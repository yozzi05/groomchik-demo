# ГрумЧик — демоверсия нового сайта

Интерактивное демо для груминг-салона «ГрумЧик» (Ростов-на-Дону): главная, подбор ухода, услуги и цены, работы, мастера, запись в 4 шага, личный кабинет владельца питомца и концепция программы лояльности.

**Это демо.** Заявки, сообщения и платежи никуда не отправляются. Кабинет — вымышленный профиль, данные хранятся только в `localStorage` браузера (ключ `groomchik-demo`, версия схемы `1`).

## Запуск

```bash
npm install
npm run dev       # разработка
npm test          # проверки расчёта бонусов и переходов состояний записи (vitest)
npm run build     # сборка в dist/
```

## Публикация на GitHub Pages

- `vite.config.ts` → `base: './'`: все пути относительные, сборка работает из любой подпапки (`https://user.github.io/repo/`).
- Маршрутизация через хеш (`#/kabinet`, `#/zapis`): прямое открытие кабинета и обновление страницы не дают 404.
- Workflow `.github/workflows/pages.yml` собирает, тестирует и публикует `dist/` при пуше в `main` (в настройках репозитория: Pages → Source: GitHub Actions).

## Структура данных

| Файл | Что внутри |
|---|---|
| `src/data/salon.ts` | **Подтверждённые сведения** о салоне: адреса, телефоны, часы, правила визита, отзывы, акции из прайса, школа и документы. Внизу — `openQuestions`, спорные данные. |
| `src/data/services.ts` | Услуги: описания со страниц сайта, таблицы цен из прайс-листов (изображения). `demoPrice` — условная сумма только для демонстрации бонусов. |
| `src/data/masters.ts` | Мастера: Инна Бродилова и Алёна (без привязки к салонам — она не подтверждена). |
| `src/data/media.ts` | Фотографии работ и их подписи, источники. |
| `src/data/loyalty.ts` | **Предлагаемые** условия программы лояльности (не действующая программа). |
| `src/data/demo.ts` | **Демонстрационные** питомцы, записи, бонусы. Даты строятся от текущего дня. |
| `src/lib/model.ts` | Чистая логика: запись, перенос, отмена, завершение визита, резерв/возврат бонусов, купон. |
| `src/lib/time.ts` | Время в Europe/Moscow и демонстрационное расписание. |

Изображения скачаны с groomchik.ru и оптимизированы скриптом `scripts/assets.mjs` (WebP, две ширины, манифест размеров `src/data/imageSizes.json`).

## Программа лояльности (демо-предложение)

- 5% бонусами от суммы, оплаченной деньгами, после завершённого визита; 1 бонус = 1 ₽.
- Списание до 20% стоимости и не больше баланса; на часть, оплаченную бонусами или купоном, бонусы не начисляются.
- За отменённые и будущие записи бонусы не начисляются; при отмене резерв возвращается; повторное завершение визита невозможно.
- Карточка пяти визитов → купон 300 ₽; купон не суммируется с бонусами.

Пример: 2 000 ₽ → списание до 400 → деньгами 1 600 → +80 бонусов (покрыто тестом).
